# nest-camera-cat-poop

Watches the Litter Box through a Nest camera, works out the Outcome of each Visit, and tells the Partner through a Speaker when there is Poop to clean up or the Dog is at it.

- [Setup](docs/setup.md): install, private config and secrets
- [Where to change things](docs/configuration.md)
- [Importing camera history](docs/history-import.md) for training
- [Code layout and dev rules](CONTRIBUTE.md)
- [Glossary](GLOSSARY.md): the words used in code and docs
- [Decisions](docs/adr/)

Quick start: `make setup`, edit `config.toml` and `.env`, then `make check` and `make test`.
